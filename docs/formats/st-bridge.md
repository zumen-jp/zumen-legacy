# ST-Bridge の扱い

`@zumenjs/stb` は、構造設計データの国内標準 ST-Bridge（`.stb`、XML）を、buildingSMART Japan 構造設計小委員会の
ST-Bridge XML ファイル仕様書 ver.2.1.1（2026-04-15 付、2026-07-29 公開）と ver.2.0.2（2020-12-16 付 Revision 2）、
同じ版の XML Schema に従って読む。2.0 系（2.0.0〜2.0.2）と 2.1 系（2.1.0・2.1.1）を読み、1.x は読めない旨のエラーにする。
仕様書の節をコードのコメントに書いた。仕様書と XML Schema は配布せず、仕様書の文は転記しない。

```text
bytes ─▶ decodeXml（UTF-8・Shift_JIS）─▶ parseXml ─▶ buildModel ─▶ StructureModel ─▶ StructureView（three.js）─▶ StbViewer（React）
```

`StructureModel` は図面の `Scene` とは別の、3D の表示用モデル（全体座標系の mm、Z が鉛直上向き）。
部材ごとに立体（断面の 2D の輪郭と押し出しの向き、または 3D の輪郭の列）、属性の一覧、元の XML の属性を持ち、
同じ断面の輪郭は部材の間で共有する。三角形分割と WebGL への転送は `./three` で行う。

## 読み方

- 文字コードは XML 宣言の UTF-8・Shift_JIS に従う。宣言と中身が食い違うファイルがあるため、UTF-8 と宣言して
  UTF-8 として正しくないものは Shift_JIS で、Shift_JIS と宣言して UTF-8 の多バイト文字として正しいものは UTF-8 で読み直し、
  その旨を知らせる（STB-DiffChecker の見本は Shift_JIS と宣言した UTF-8）。先頭の BOM・空白も受け付ける。
- 部材座標系は仕様書 2.6 のとおり、材軸と「対応断面軸」から作る（柱は Y、梁・ブレースは Z）。
  回転（rotate）は始端から終端を見て時計回りが正（材軸まわりの右ねじ）で、断面を回してからオフセットを足す。
- 基準点: 柱は図心、梁は天端の幅中心（断面は節点から下に付く）、ブレースは外形を包む長方形の中心、スラブは上面、
  壁は厚さの中心、フーチングは図心と下端、杭は図心と杭頭、パラペットは下端の中央、布基礎は天端の幅中心。
- 鉄骨断面は「成」を鉄骨断面の基準方向とし、柱では部材の Y に向ける。`isReferenceDirection="false"` は 90 度回す。
  溝形鋼・山形鋼・リップ溝形鋼は、仕様書の図のとおり進行方向に向かって右を開く（山形鋼は幅方向の脚を上にする）。
  StbSecSteel に定義のない形状名は、規格品の呼び方（`H-400x200x8x13`、`□-400x400x22`、`P-318.5x10` など）から寸法を読み、
  その旨を知らせる。
- 2.0 と 2.1 で名前の違う断面の要素（`StbSecColumn_RC_Rect` と `StbSecColumnRect`、`StbSecBeam_RC_Haunch` と
  order 付きの `StbSecFigureBeam_RC` など）を同じ形に読む。
- 梁の変断面: 2.1 は order の区間を `StbGirderConcreteSwitch`・`StbGirderSteelSwitch` の距離で並べる。2.0 はハンチ位置
  （基準点から）と継手位置（柱の中心から）で区間を切り、SLOPE はテーパー、DROP は段で描く。5 種類の断面は仕様書 6.7.6 の
  5-1・5-2 の場合分けに従う。位置の記述がないときは等分し、その旨を知らせる。
- 外端・内端の指定（`isOutin` と `section_io_*`）で、始端が内端なら断面の始端・終端を入れ替える。
- 柱の柱頭・柱脚の断面の切り替えは、2.1 は `steel_switch_height_*`、2.0 は `joint_*` の位置で行う。
- 開口は 2.1 の `StbOpenArrangement`、2.0 の `StbOpenIdList` と `StbOpens` の両方を読み、壁・スラブの第 1 点から、
  1 点目から 2 点目の向きを X、それを反時計回りに 90 度回した向きを Y として位置を決める。
- 部材の階は、コンクリート強度の決め方（仕様書 3.2）と同じく、柱・ブレースは上の節点、梁・スラブは始端・第 1 節点、
  壁は最終節点が属する階とする。節点の階は `StbStory` の `StbNodeIdList`、なければ代表高さの近い階で決める。
- コンクリート強度は、部材 → 断面 → 基準の節点の階 → StbCommon の順に最初の定義を使い、どこから決めたかも示す。
- 通り芯で絞るときは、部材を定める節点がすべて通り芯の上（軸の節点の一覧にあるか、5 mm 以内）にある部材を示す。

## 推測で補った解釈

仕様書の文と図から決められなかったもの。

| 内容 | 扱い |
| --- | --- |
| 柱・ブレースで頭部・脚部の断面が違い、切り替え位置がない | 等分して切り替える |
| RC スラブのテーパー・ハンチ | 最も厚い部分の厚さで一様に描く |
| 矩形テーパーのフーチング | 外周を先端厚さ、中央を根元厚さとし、上面の平らな範囲を外形の半分とする |
| 布基礎の連続基礎断面 | 脚部の付く側を根元厚さ、反対側を先端厚さとして上面を傾ける |
| 場所打ち杭の拡頭・拡底のテーパー角 | 鉛直からの角度とする |
| 外端・内端の指定がない梁（`isOutin` だけ） | 断面の始端を部材の始端に置く |

## 描かない・代わりに示すもの

`notices`（読み取りの注意）に種類と件数を出す。

| 内容 | 扱い |
| --- | --- |
| 配筋、継手・接合部・溶接の詳細、梁貫通孔、鉄骨梁端部の拡幅 | 描かない |
| 免震装置・制振装置 | 描かない |
| SRC の内部の鉄骨 | 外形のコンクリートだけを描く |
| 製品型番一覧表に寸法がある製品（デッキの山、既製スラブ、認定工法の杭など） | 寸法の分かる部分だけを描く（デッキはトップコンクリートの厚さ） |
| 荷重用のスラブ・壁（LOAD） | 厚さのない半透明の面で示す |
| 断面の分からない部材（StbSecUndefined、寸法の読めない鉄骨形状など） | 配置基準線を線で示し、選択できる |
| 計算データ（StbCalData）・解析モデル（StbAnaModels）・拡張情報 | 表示しない |

製品型番一覧表は buildingSMART Japan の加盟者などに限って公開されているため、それに依存する寸法は再現できない。
構造計算・法適合の確認の代わりにはしない。buildingSMART Japan の公認・認証を受けたものではない。
