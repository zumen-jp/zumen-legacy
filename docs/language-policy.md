# 言語と対象利用者の方針

zumen は、日本の建築・土木の図面を扱う、日本語ファーストのライブラリです。

## 対象

日本の設計・施工・維持管理と、そのためのソフトウェア開発を主な対象にします。SXF による電子納品、Jw_cad、日本語の図面、国土交通省の CAD 製図基準を重視します。DXF・DWG・PDF も日本の実務で扱う図面として対応します。

## 日本語を標準にする範囲

README、利用ガイド、API の説明、設計判断、開発手順、サンプル画面、属性ラベル、注意事項、エラー、CLI のヘルプ、MCP のツール・引数の説明、Issue・PR の本文は日本語を標準にします。

文書は短い文と具体的な用語で説明し、必要な前提から読めるようにします。規格名・一般的な技術用語は、無理に訳して意味を変えません。

## 互換性を保つ範囲

関数名・型名・パッケージ名、コマンドとオプション、JSON キー、エラーコードは既存の識別子を使います。利用者に見せる日本語と、プログラムが読む識別子を分けます。

図面由来のレイヤ名・文字・ファイル名・単位・メタデータは、元の意味を保って読み取ります。日本向けであっても、海外の図面を勝手に mm に読み替えません。表示用座標と計測の単位は既存 API の契約に従います。

## 英語の扱い

日本語の文書を入口・正本とし、英語版は任意の補足にします。従来の詳細な実装記録・対応表・検証履歴は `.en.md` に保存し、日本語の各資料から参照できます。日本語版は利用と保守に必要な要点を整理し、英語の補足には元の細部とコード例を残します。既存の見出しへのリンクも維持します。

第三者のライセンス本文、仕様の引用、プロトコル上の定義済み値は原文を保ちます。日本語の方針を変更する場合は設計判断として記録します。
