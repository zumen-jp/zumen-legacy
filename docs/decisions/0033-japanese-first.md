# 0033: 日本の実務と日本語を標準にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-24 |
| 状態 | 採用 |

## 背景

SXF・Jw_cad・日本語の図面・国土交通省の CAD 製図基準が主要な用途である一方、README・開発資料・CLI・MCP は英語が中心だった。日本の利用者が導入・開発・運用を一貫して日本語で進められるよう、対象と既定言語を揃える。

## 選択肢

- 英語を正本として日本語版を補助にする。
- 両言語を常に同じ量で更新する。
- 日本語を入口と正本にし、英語は必要に応じた補足として残す。

## 決定

3 つ目を選ぶ。日本の建築・土木の実務を優先し、利用者向けの文書・画面・メッセージ・CLI・MCP と開発の説明を日本語にする。既存の英語資料は `.en.md` に保存し、日本語のガイド・設計判断の要約から細部を参照できるようにする。

API 名・型名・コマンド・JSON キー・エラーコードと、図面内の名前・文字・単位は既存の契約を維持する。第三者のライセンスと仕様の引用は原文を保つ。

## 影響

README.md が日本語の入口、README.en.md が英語版になる。README.ja.md は互換の案内を残す。既存の文書の見出しへのリンクと詳細な仕様・検証履歴を保存する。これまでの「設計判断は英語」という開発規則を日本語へ変更する。

英語の補足は当時の詳細記録であり、今後の説明と変更は日本語を優先する。日本向けの方針は、ST-Bridge の公開条件や依存ライセンスに関する決定 0013 を変更しない。
