# 0017: DXF・DWG の編集に注記と定義の追加を広げる

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-22 |
| 状態 | 採用 |

このページは既存判断の日本語の要約です。詳細な条件と当時の議論は英語の補足資料に保持しています。

## 背景

受領図面に寸法・表題欄・ハッチングなどを足すには、単純な線や文字だけでは不足する。

## 選択肢

作図済みの線にすべて分解する、各形式の定義と図形を編集操作で追加する方法を比較した。

## 決定

部品・文字スタイル・線種・寸法スタイルの定義と、寸法・ハッチング・文字設定・属性・用紙・引出線を追加できるようにする。

## 影響

編集操作の検証と未変更部分の保存を共用する。図形とその依存定義を正しく書き、後の作図機能の基礎にする。

## 英語の補足資料
